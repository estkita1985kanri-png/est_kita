資源物

（古紙・古着・空き缶）
収集日金
出す時間収集日の朝 8時30分まで決められた集積所へ。前日の夜に出すのはやめましょう（カラス・においの原因になります）

〇このごみに入れるもの

古紙類新聞・ダンボール・紙パックは3種類に分けて。ほかに雑誌・雑多な紙（本、ノート、封筒、包装紙、紙袋、芯）
古着類ぬれたり汚れたりしていない古着
空き缶アルミ缶、スチール缶、お菓子の缶、缶詰の缶、使い切ったカセットボンベ

出し方

  1. 1古紙は新聞・ダンボール・紙パックを3種類に分ける（雑誌・雑多な紙はまとめて）
  2. 2ひもで束ねるか、紙袋・無色透明・白色半透明の45リットル以下の袋に入れる
  3. 3紙パックは水ですすいで開く
  4. 4空き缶は軽くすすぐ。カセットボンベは使い切って、穴を開けずに出す
袋・出し方の決まり　ひもで束ねる／紙袋／無色透明・白色半透明の45リットル以下の袋

✕注意すること

  • 食品や油で汚れた紙、手で破れない紙、金属が箔押しされた紙 → 燃やすごみ
  • 紙パックの内側が銀色のもの → 燃やすごみ／ぬれ・汚れた古着 → 燃やすごみ
  • カセットボンベに穴を開けない（必ず使い切ってから出してください）
  • 袋に異物を混ぜない（ビニールがさなどを一緒に入れない）
